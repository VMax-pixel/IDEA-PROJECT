# IDEA-PROJECT
An AI-powered creative workspace that helps people turn ideas in their heads into visual concepts. Tell it, shape it, see it.
**Live app:** https://idea-project-ku2v.onrender.com

## How it works
1. **Tell**: describe your idea.
2. **Shape**: the AI asks clarifying questions and proposes three creative directions.
3. **See**: visual generation (coming next).

Built with Node.js, Express and the Google Gemini API. Hosted on Render and installable on a phone as a web app.
